# 🖥️ Animated Desktop & Taskbar Customization App  

An application that allows you to set **animated desktop wallpapers** and customize the **taskbar**.  

## 🎨 Wallpapers  
Set **Video, GIF, or Webpage** as your desktop wallpaper.  

![1](https://github.com/user-attachments/assets/8cb5e0b8-1ec7-41aa-a5a9-4f88b81bc525)

## ⚙️ Taskbar Customization  
- Change the **accent, color, and transparency** of the taskbar.
  ![2](https://github.com/user-attachments/assets/c3b2cadd-9f77-454b-8b48-1474cba33804)

- Configure an **additional taskbar** that appears only when apps are running in fullscreen mode.
